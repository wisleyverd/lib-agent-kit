# Diretrizes para Claude Code CLI

Configuração e regras de contexto para Claude Code e assistentes baseados em Claude.

---

## 1. Princípios Operacionais

- **Pensamento Crítico e Análise Profunda**: Identifique a causa-raiz dos problemas e implemente soluções robustas e sustentáveis.
- **Segurança de Código**: Evite comandos destrutivos sem confirmação.
- **Aderência aos Padrões de Projeto**: Consulte as convenções em `agent-core/conventions/`.

---

## 2. Comandos Frequentes e Boas Práticas

- Executar testes antes de submeter alterações.
- Verificar tipagem estática e linter.
- Manter commits e mensagens de PR claras e semânticas.
